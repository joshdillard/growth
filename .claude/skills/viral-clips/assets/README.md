# Brand assets

Drop the channel logo here as `logo.png` (transparent PNG recommended).
It gets scaled to 200 px wide and overlaid at the top-left of every short.

To change the title-card colors, edit the `Style: Title` line in
`scripts/make_clip.py` (`PrimaryColour` = text, `OutlineColour` = box,
ASS colors are `&HAABBGGRR`).
