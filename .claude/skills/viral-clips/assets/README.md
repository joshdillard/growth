# Brand assets

Drop the channel logo here as `logo.png` — the "DISTURBING THE PEACE"
wordmark, transparent PNG. It gets scaled to 260 px wide and overlaid at
the top-left of every short (tune `LOGO_WIDTH` in `scripts/make_clip.py`).

To change the title-card colors, edit the `Style: Title` line in
`scripts/make_clip.py` (`PrimaryColour` = text, `OutlineColour` = box,
ASS colors are `&HAABBGGRR`).
